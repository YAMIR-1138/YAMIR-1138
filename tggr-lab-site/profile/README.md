# TGGR Lab

**Translational Genetics and Genomics Research** · Genetics Institute, Tel Aviv Sourasky Medical Center · Faculty of Medicine, Tel Aviv University

We look for the genes behind rare disease in the families who come to the Genetics Institute, then work out what those genes do. Along the way we build tools, and we put them here.

**[tggr-lab.github.io](https://tggr-lab.github.io/)** · [The lab at Ichilov](https://www.tasmc.org.il/rd/en/next-unit/research-laboratories/genetics/the-translational-genetics-and-genomics-research-laboratory-prof-hagit-baris-feldman/)

### Tools

| | |
|---|---|
| [**Pellaeon**](https://tggr-lab.github.io/pellaeon/) | Talk to UCSF ChimeraX in plain English. A chat panel that runs the commands for you and shows every one it ran. On the ChimeraX Toolshed. |
| [**GPCompaRe**](https://tggr-lab.github.io/GPCompaRe/) | What changes when a receptor switches on: residue contacts compared between the active and inactive states of 283 human Class A GPCRs. |
| [**Incubator CO₂ monitor**](https://tggr-lab.github.io/incubator-co2-monitor/) | A DIY CO₂ and temperature monitor for cell culture incubators, built on an ESP32. Three parts, six wires, full build guide. |
